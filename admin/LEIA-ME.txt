ENTREGA FLASH — PAINEL ADMIN ULTRA MASTER

Este pacote contém somente o app/PWA administrativo.

PARA USAR NO SITE ATUAL:
1. Abra a pasta /admin do seu projeto.
2. Substitua os arquivos pelos deste pacote.
3. Publique normalmente.
4. Acesse /admin/ no celular.
5. No navegador Android, use "Adicionar à tela inicial" / "Instalar app".

O painel abre em modo standalone, com splash premium, safe-area do Android, toque mobile otimizado e cache/versionamento próprios.

IMPORTANTE:
- A lógica existente do painel e a conexão do banco foram preservadas.
- Este ZIP não altera a área pública de clientes/motoristas.
- Ele não é um APK compilado; é o pacote administrativo pronto para ser instalado como PWA e usado como base para gerar um APK/AAB dedicado depois.
